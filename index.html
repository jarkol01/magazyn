Jak zdobyć token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token (classic), zaznacz tylko zakres gist, expiration „No expiration”.
  3. Skopiuj token i wklej powyżej. Ten sam token wpisują wszyscy pracownicy (raz, na swoim telefonie).
